# Privacy Policy for SAP Browser Automation

## Introduction

SAP Browser Automation is an AI web automation Chrome extension. This Privacy Policy explains how the extension handles your data.

## Data Collection and Processing

### Local Processing
- SAP Browser Automation operates within your browser
- Login credentials and cookies never leave your browser
- User data is processed locally by default

### Anonymous Analytics (Optional)
**Analytics is enabled by default but can be disabled anytime** in extension settings.

**We collect only:**
- Task metrics (execution times, error categories)
- Domain names visited (e.g., "amazon.com" - not full URLs)
- Anonymous usage statistics
- Anonymous user identifier (randomly generated)

**We never collect:**
- Personal information, credentials, or authentication data
- Full URLs, page content, screenshots, or task instructions
- Any personally identifiable information

## Third-Party Services

When you configure LLM providers, requests are sent directly from your browser to those providers using your API keys. Review each provider's privacy policy for details on how they handle API traffic.

## Contact

For privacy questions, contact your system administrator or the team maintaining this extension.
